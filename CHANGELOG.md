# Changelog

All notable changes to Xiaoya Framework are recorded here.

## 0.3.0 — 2026-09-12

- Added bounded cognition: attention gate, conscious workspace and permission-veto arbitration.
- Added persistent Self Model, curiosity candidates, reflection candidates and budgeted goals.
- Added declarative Skill evolution with sandbox validation, user confirmation and rollback.
- Added provider-neutral LLM, TTS, STT and avatar contracts.
- Added XiaoyaBench and a local-only release audit workflow.

The package contains contracts and deterministic local tests only. Character media, model weights, credentials and machine-specific runtime state stay outside the public tree.
