# Code of Conduct

We want Xiaoya Framework to be a welcoming, technically rigorous and privacy-
respecting project. Be respectful, assume good faith, explain disagreements
with evidence and protect private media, credentials and user data.

Unacceptable behaviour includes harassment, discrimination, doxxing, publishing
secrets or private assets, and intentionally weakening permission or audit gates.
Project maintainers may remove content or restrict participation when needed to
keep the community safe.

For a private concern, contact the repository owner through the GitHub profile
or use the security process in [SECURITY.md](SECURITY.md). Do not include secrets
in public issues.
