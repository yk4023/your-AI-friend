# Xiaoya Framework architecture

```text
event → subconscious score → attention gate → conscious workspace
      → drive/reality/value arbitration → goal/skill/provider/avatar
      → observation → verification → reflection → candidate → user gate
```

The Permission Engine is the final veto. Core contracts are provider-neutral; Qwen, vLLM, TTS/STT, MuseTalk, LiveTalking and ComfyUI are optional adapters, not core dependencies.
