# Security policy

Xiaoya Framework is local-first. The public package must not contain credentials, model weights, private media, chat history or host-specific paths.

Permission checks are intentionally a final veto, and Skill promotion/rollback requires explicit user confirmation. Do not weaken those gates to make a demo pass.

For a suspected security issue, keep the report local to the project owner and include a minimal reproduction. Do not attach secrets or private runtime data.
